# 위탁운용 분석 자료

이 폴더의 엑셀 파일은 Git에 올라가지 않습니다(`.gitignore`). 파일을 넣은 뒤 아래 명령으로 보고서를 다시 만드세요.

## 주간·월간 운용분석보고서 (`report.html`)

```
python dashboard_report.py
```

파일명에 아래 키워드가 들어 있으면 자동으로 찾습니다 (같은 키워드가 여러 개면 이름순 마지막 파일).

| 키워드 | 내용 |
|---|---|
| `기준가` | 일자별 기준가 현황 (기준가·BM지수·듀레이션·YTM·순자산·좌수) |
| `매매` | 채권매매 손익률 (거래일·펀드·종목·만기·결제액·매매손익) |
| `헤지` | 해외채권형 환헤지비율 — 파일명의 `26년 ○○ 헤지비율`에서 ○○를 운용사명으로 사용 |

## 25년말 보유내역 포트폴리오 분석 (`report_holdings.html`)

```
python dashboard_report_holdings.py
```

파일명에 `취합본`이 들어간 보유내역(집합투자증권명세) 엑셀을 사용합니다.
