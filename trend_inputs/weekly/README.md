# 주간 동향 자료 폴더

이 폴더에 금리·환율 엑셀(`일자 / 환율 / 미국10y / 한국3y`)을 올리면 GitHub Actions(`update_trends.yml`)가
데이터 검증 → AI 조사·작성 → 한글(HWPX)·워드(DOCX) 생성 → 대시보드 「주간 동향 분석」 탭 게시까지 자동으로 진행합니다.

- **기본**: 대시보드 「주간 동향 분석」 탭 → 📤 자료 업로드 (업로드 비밀번호만 입력, 중계 서버 relay/worker.js 경유)
- **GitHub에서 직접**: 이 폴더 화면에서 `Add file → Upload files` → 엑셀을 끌어다 놓고 `Commit changes`
- 파일명에 기준일(예: `주간동향_261106.xlsx`)을 넣으면 그 날짜, 없으면 가장 최근 금요일을 기준일로 작성합니다.
- 같은 파일명으로 다시 올리면(내용이 바뀐 경우) 보고서를 새로 작성합니다.
